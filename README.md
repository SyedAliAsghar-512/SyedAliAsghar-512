## 🚀 Main Project: StreakSphere

[**StreakSphere**](https://streaksphere.app)  
The new era of social media—a secure, modern productivity and connection platform built to scale:

- ✨ **Core Features**: 
  - **Global Activity Feed**: Explore verified community moments (For You, World, Country, City, Friends) with secure in-app reporting and moderation.
  - **Relationship Streaks & Status Pills**: Never guess how they feel; view live mood badges and real-time relationship pills.
  - **AR Spatial Chat**: Augmented reality-enabled chatrooms bringing accountability and social connection into physical space.
  - **AI-Verified Activity Competition**: AI engine verifies activity proof before granting points to dominate local and global leaderboards.
  - **End-to-End Encryption**: Secure calls, messages, and mood entries.
- ⚡ **Recent Releases (v6.0.0)**: Shipped StreakSphere+ Premium, enhanced moderation with automatic snapshot caching, and advanced global filtering.
- ☁️ **Infra & DevOps**:
  - **Self-managed Ubuntu/Linux server** (fully configured, secure, automated deploys)
  - **Docker, CI/CD, Nginx reverse proxy, SSL (Let’s Encrypt), PM2 monitoring**
  - **Cloudflare CDN** for performance and anti-DDoS protection
  - **Azure App Services** for scalable API deployments
  - **Vercel** for blazing-fast frontend delivery
- 📲 **Tech Stack**: React Native, Node.js, Express, MongoDB, Socket.io
